CLASSMATE — STUDENT NOTES & PROJECT PLANNER
Your Study Partner.

FILES
- index.html       : Website structure
- style.css        : Design and responsive layout (light theme)
- script.js        : Notes, assignments, projects, search, filters and local storage
- classmate-logo.png : ClassMate logo used in the website

HOW TO RUN IN VS CODE
1. Extract this ZIP file to a folder on your computer.
2. Open VS Code.
3. Choose File > Open Folder and select the ClassMate_Student_Planner folder.
4. Install the Live Server extension if it is not installed.
5. Right-click index.html and choose Open with Live Server.
6. The website will open in your browser.

FEATURES
- Dashboard with summary cards
- Create, search, filter and delete class notes
- Export notes to a text file
- Add and track assignments with priorities and completion status
- Plan projects and track progress
- Data is saved in your browser using localStorage
- Responsive layout for desktop and mobile
- Modern ClassMate logo and blue branding
- Light theme only; dark mode has been removed

NOTE
This is a front-end project. Data is stored in the current browser on this device. It does not use a server/database, and payment apps are not connected.
